Support

Rapsod turns your Mac into an audiobookshelf server and gives you native apps to listen on it. Your books and the server stay on your Mac; Rapsod has no server of its own.

The interface is in Polish for now, so this page gives the Polish names of buttons and settings in brackets. English is on the way.

Getting started

  1. Install Rapsod. Download the disk image from GitHub Releases and drag Rapsod to Applications. It needs macOS 27 on a Mac with Apple silicon.
  2. Pick your library folder. Rapsod lives in the menu bar. Choose the folder with your audiobooks; the server starts, scans it, and can start again at login. You can add more folders and libraries later, or drop a folder on the menu bar icon.
  3. Listen. Open the Library window from the menu bar to browse, listen and read on the Mac.
  4. Connect a phone, if you like. Turn on sharing on the home network, then use Connect phone… (Podłącz telefon…) in a person's profile under Settings › Users (Ustawienia › Użytkownicy). Rapsod's iPhone app scans the QR code; other audiobookshelf apps sign in with the address, user name and password the window shows.

FAQ

What is audiobookshelf, and is Rapsod made by its authors?

audiobookshelf is an open-source, self-hosted audiobook and podcast server by advplyr. Rapsod bundles it unmodified, with Node.js and FFmpeg, and adds a native Mac app around it. Rapsod is an independent project, not made by the audiobookshelf developers.

Do I need Docker, Homebrew or a terminal?

No. Everything the server needs is inside the app and is updated with it. The only optional extra is cloudflared, if you want a Cloudflare Tunnel (see below).

Which apps can I listen with?

On the Mac, Rapsod itself. On iPhone, Rapsod's own app is in development and can be built from source; until it ships, any audiobookshelf app works, as does the audiobookshelf web interface in a browser.

How do I listen away from home?

By default the server is reachable only from your Mac, or from your home network once you turn sharing on. For access from anywhere, enter an address of your own (Tailscale, a VPN, your own tunnel), or set up a Cloudflare Tunnel: create a tunnel in your Cloudflare account, install cloudflared (from Cloudflare's releases or with Homebrew), and paste the tunnel's token into Rapsod, which then starts and watches cloudflared for you. Your phone gets the new address from a fresh QR code.

Is the connection on my home network encrypted?

No. On the home network the server speaks plain HTTP, like audiobookshelf itself, so other devices on the same network could see the traffic. A Cloudflare Tunnel or an address of your own with HTTPS encrypts the connection from outside.

How does the text follow the narrator?

When a book comes with its EPUB, Rapsod on the Mac runs speech recognition on the recording and matches every sentence to its place in the audio. It all happens on your Mac; the first time, macOS may download Apple's speech model for the language. The result is shared with the iPhone app through your server.

How are sponsor segments in podcasts found?

From the episode's chapters and feed data, without sending the episode or a transcript anywhere. If you want more, enter an OpenAI-compatible API, a model and your key on the Mac, and agree to send transcripts to it: Rapsod then transcribes downloaded episodes on your Mac and sends the text to that API. Nothing is sent until you set this up.

Why do I need a key for Podcast Index?

Podcast Index gives out free keys after you sign up on its site. Without one, podcast search still uses Apple Podcasts and fyyd.

How does Rapsod update?

Once a day it asks GitHub whether there is a newer release, and offers it to you. When you choose to install, it downloads the update from GitHub, checks it against a checksum and Apple's notarization, and restarts. Automatic checks can be turned off in Settings › General (Ustawienia › Ogólne › Aplikacja).

Can I move from an existing audiobookshelf server?

Rapsod runs its own copy of the server with its own data folder. You can restore an audiobookshelf backup into it from the backups settings, and add the folders your books are in.

Which devices does it need?

macOS 27 on a Mac with Apple silicon. Rapsod's iPhone app, when it ships, will need iOS 27.

Reporting a problem

Report problems on GitHub: github.com/lakafior/rapsod/issues, or write to rapsod@smigi.net.

Include:

  • Rapsod version (in About Rapsod)
  • Mac model and macOS version
  • Steps to reproduce, and the server log from the status window if the server is involved

Never paste a password, an API key, a tunnel token or a pairing QR code.
